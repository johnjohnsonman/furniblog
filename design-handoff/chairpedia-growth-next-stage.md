# 다음 단계: 계산기 완성 · 스토어 · 제품 상세

대표님 승인 방향: 계산기를 마무리하면서 스토어 확장과 의자 상세 페이지 품질을 함께 높인다. 제품 상세에는 관련 유튜브 영상을 활용한다.

## 이번 로컬 변경

- 기존 제품 상세는 products → videos.chair_id 연결로 공개 영상 최대 6개를 표시하고 클릭 시 플레이어를 로드한다.
- 조회수 순 후보 30개 중 무작위 6개를 고르던 것을 조회수 순 6개로 변경. 같은 조회수는 ID 순으로 고정한다. 조회수는 품질 인증이 아니다.
- 영상 제목을 잘라 표시하지 않으며, 조회수 미확인은 0회와 구분한다.
- 새 영상 추가, 영상 내용 검증, 운영 배포는 이번 변경에 포함하지 않았다. DB 모델 연결만으로 영상 내용의 정확성을 보증하지 않는다.

## 다음 실행 순서

1. 제품별 공개 영상 보유 현황을 읽기 전용으로 집계하고, 유입 있는 제품부터 모델 일치·재생 가능 여부·출처를 확인한다.
2. 상세 페이지에 실측/제조사 근거, 옵션 차이, 비교 대안, 관련 영상, 체험 매장을 일관되게 연결한다. 영상 리뷰 의견은 제조사 사양과 구분한다.
3. 스토어 길찾기·웹사이트·전화·예약 클릭 측정 현황을 점검하고 누락을 보완한다.
4. 반응 있는 지역의 매장 방문 조건과 정확한 모델 체험 여부를 우선 보강한다. 브랜드 취급을 모델 체험 확인으로 간주하지 않는다.
5. 계산기 공개 구성 선택과 모바일·오류 상태를 브라우저 검증하고 화면/API 전환 시간을 측정한다.

배포 여부·데이터 적용 여부·검증 대기를 각각 보고한다. 현재 브라우저 검증과 성능 실측은 미완료다.
