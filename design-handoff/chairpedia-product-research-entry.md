# 제품 상세 탐색 연결 — 2026-09-20

로컬 공통 ProductChairTabs 개요에 사양·연결 영상·모델 필터가 적용된 스토어 찾기를 추가했다. 영상이 없는 제품은 영상 버튼을 표시하지 않는다. 영상 탭 유무에 따라 데스크톱 탭을 4열/5열로 맞춘다. 탭 선택 이벤트는 유효한 탭만 허용하고 모션 축소 설정을 존중한다.

영상 의견과 사양 근거의 차이, 방문 전 모델·방문 조건 확인 안내를 표시한다. 매장 내 정확한 모델 보유를 새로 보증하지 않는다.

Leap V2 공개 데이터에는 7개 영상이 연결되어 있다. 유튜브 페이지 2개를 열어 검증하려 했으나 도구가 페이지를 가져오지 못했다. 따라서 재생 가능·내용 검수 완료로 분류하지 않는다. 기존 영상 데이터는 변경하지 않았다.

공통 컴포넌트 변경이므로 적용 시 다른 의자에도 동일한 탐색 구조가 제공된다. 제품별 콘텐츠를 새로 작성하거나 검색 성과를 검증한 것은 아니다. 운영 배포·브라우저 화면 확인은 미완료다.

다음: 영상의 모델 일치와 재생 확인, 우선 제품의 근거·비교 콘텐츠 보강, 실제 브라우저의 상세→스토어 이동과 계산기 전환 검증.
