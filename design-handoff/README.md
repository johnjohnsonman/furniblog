# Chair Fit Calculator design handoff

Send Claude Design the files in this folder together with the Chairpedia live URLs below.

## Files to attach

1. `chair-fit-calculator-interaction-brief.md` — complete product, interaction, motion, showroom, mobile, accessibility, and state requirements.
2. `asset-manifest.md` — existing assets to reuse and new assets/components to design.
3. `claude-design-request.md` — the task prompt and expected output format.

## Reference URLs

- Current Chairpedia: `https://www.chairpedia.com/`
- Existing AI finder: `https://www.chairpedia.com/chair`
- Existing recommendation flow: `https://www.chairpedia.com/find-your-chair`
- Existing showroom experience: `https://www.chairpedia.com/stores`
- Chair catalog: `https://www.chairpedia.com/products`
- Comparisons: `https://www.chairpedia.com/compare`

Claude Design should inspect the live site for brand continuity but should not preserve the current finder layout merely because it already exists.

## Recommended delivery procedure

1. Create a new Claude Design task.
2. Attach all three Markdown files from this folder.
3. Paste the contents of `claude-design-request.md` as the task message.
4. Add the six reference URLs above.
5. Ask for desktop and mobile concepts before high-fidelity production screens.
6. Require a clickable prototype that covers opening, inputs, result reveal, comparison, and showroom selection.
7. Export or return the final design source, component specifications, motion notes, and any generated SVG assets.

## Do not send

- Environment-variable files
- Supabase credentials
- Google service-account keys
- Raw user analytics exports
- Unverified product photos copied from retailer sites
