Send the active files below together with the Chairpedia reference URLs.

1. `chairpedia-authority-upgrade-brief.md` — active visual, authority, evidence, interaction, SEO, and generative-search direction.

4. `asset-manifest.md` — existing assets to reuse and new assets/components to design.

`chair-fit-visual-asset-brief.md` and `gpt-image-chairman-chairbot-prompts.md` are archived ChairPark character references. Do not attach them as active Chairpedia direction.

## Recommended delivery procedure

1. Create a new design task.
2. Attach the five active Chairpedia Markdown files listed above.
3. Paste the contents of `claude-design-request.md` as the task message.
4. Add the six reference URLs above.
5. Ask for desktop and mobile concepts before high-fidelity production screens.
6. Require a clickable prototype that covers opening, inputs, result reveal, comparison, and showroom selection.
7. Export the final design source, component specifications, motion notes, and any generated SVG assets.

## Do not send

- Environment-variable files
- Supabase credentials
- Google service-account keys
- Raw user analytics exports
- Unverified product photos copied from retailer sites
