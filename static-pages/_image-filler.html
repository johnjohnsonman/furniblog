🪑 상세페이지 이미지 채우기

버튼 클릭으로 이미지를 넣고, 완성된 HTML을 복사해 카페24에 붙여넣으세요. (모든 체어파크 상세페이지에 재사용 가능)

① 붙여넣기 · 상세페이지 HTML 파일(예: itoki-act2.html)을 메모장으로 열어 전체 복사 → 아래 칸에 붙여넣고 [불러오기].

② 이미지 올리기 · 이미지 자리마다 [파일 선택] 버튼으로 사진을 고르면 오른쪽 미리보기에 바로 들어갑니다.

③ 복사 → 카페24 · [완성 HTML 복사] 누른 뒤, 카페24 상세페이지 HTML 편집 모드에 붙여넣기.

1) 상세페이지 HTML 붙여넣기

2) 이미지 자리 (버튼으로 업로드)

먼저 HTML을 불러오면 이미지 자리가 여기에 표시됩니다.

미리보기

※ 파일 업로드 방식은 이미지가 HTML 안에 직접 박혀(base64) 용량이 커집니다. 사진이 많거나 무거우면, 카페24에 먼저 이미지를 업로드해 URL을 받아 각 자리의 ‘URL’ 칸에 넣는 편이 가볍고 빠릅니다.
